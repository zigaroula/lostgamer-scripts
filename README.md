# Lostgamer Visual Effects

Userscript non officiel qui ajoute plusieurs effets à la vue panoramique de
[Lostgamer](https://lostgamer.io/) : noir et blanc, pixelisation, flou,
inversion des couleurs, affichage pendant une seconde et détection des contours.
La petite interface s’affiche automatiquement en français si le navigateur est
en français, et en anglais dans les autres cas.

🌐 **[Voir la page de présentation](https://zigaroula.github.io/lostgamer-scripts/)**

## Installation

1. Installez l’extension [Tampermonkey](https://www.tampermonkey.net/) dans votre navigateur.
2. **Sur Chrome 138 ou une version plus récente**, ouvrez
   `chrome://extensions`, affichez les détails de Tampermonkey et activez
   **Autoriser les scripts utilisateur**. Sur une ancienne version de
   Chrome/Chromium, activez plutôt le **Mode développeur** dans la page des
   extensions. Pour Edge, utilisez `edge://extensions`. Cette étape
   supplémentaire concerne les navigateurs basés sur Chrome ; Firefox ne
   propose pas le même interrupteur.
3. Cliquez sur **[Installer le script](https://github.com/zigaroula/lostgamer-scripts/raw/refs/heads/master/lostgamer-visual-effects.user.js)**.
4. Tampermonkey s’ouvre : confirmez avec **Installer**.
5. Ouvrez ou rechargez [Lostgamer](https://lostgamer.io/).

Si Tampermonkey ne s’ouvre pas automatiquement, affichez le fichier
`lostgamer-visual-effects.user.js` sur GitHub, cliquez sur **Raw**, copiez son
URL, puis utilisez **Tableau de bord Tampermonkey → Utilitaires → Importer depuis
une URL**.

## English

Unofficial userscript that adds several effects to the
[Lostgamer](https://lostgamer.io/) panorama: grayscale, pixelation, blur,
inverted colors, one-second visibility, and edge detection. The small interface
automatically uses French when the browser language is French, and English
otherwise.

### Installation

1. Install the [Tampermonkey](https://www.tampermonkey.net/) browser extension.
2. **On Chrome 138 or newer**, open `chrome://extensions`, view Tampermonkey’s
   details, and enable **Allow User Scripts**. On an older Chrome/Chromium
   version, enable **Developer mode** on the extensions page instead. This
   additional step applies to Chrome-based browsers; use `edge://extensions`
   on Edge. Firefox does not use the same toggle.
3. Click **[Install the script](https://github.com/zigaroula/lostgamer-scripts/raw/refs/heads/master/lostgamer-visual-effects.user.js)**.
4. Tampermonkey opens: confirm by clicking **Install**.
5. Open or reload [Lostgamer](https://lostgamer.io/).

If Tampermonkey does not open automatically, view
`lostgamer-visual-effects.user.js` on GitHub, click **Raw**, copy its URL, then
use **Tampermonkey Dashboard → Utilities → Import from URL**.
