Installation

  1. Installez l’extension Tampermonkey dans votre navigateur.
  2. Sur Chrome 138+, ouvrez les détails de Tampermonkey et activez « Autoriser les scripts utilisateur ».
  3. Cliquez sur « Installer le script », puis confirmez dans Tampermonkey.

Ancien Chrome/Chromium : activez le Mode développeur dans chrome://extensions. Sur Edge : edge://extensions. Firefox n’utilise pas le même interrupteur.
